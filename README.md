# Mercel TV Windows

Windows 10 ve Windows 11 için Mercel TV.

[Son sürümü indir](https://github.com/aksucelal/mercel-tv-windows-releases/releases/latest)

## Kurulum

1. Son sürümdeki `MercelTV-Windows-...-Setup.exe` dosyasını indirin.
2. Mercel TV açıksa kapatıp kurulumu çalıştırın; Windows yönetici izni ister.
3. Lisans sözleşmesini okuyup kabul edin.
4. Varsayılan klasör `C:\Program Files (x86)\Mercel TV` olarak önerilir. Göz at ile başka bir klasör seçebilirsiniz.
5. Uygulamayı Başlat menüsündeki Mercel TV kısayolundan açın.

64 bit Windows içindir. Gerekli çalışma bileşenleri kurulum paketine dahildir. Setup kompakt boyutta açılır.

Eski 0.1.7 kullanıcı klasörü kurulumu varsa, eski kısayolların karışmaması için önce eski kurulumu Windows Ayarlar → Uygulamalar bölümünden kaldırın. Kullanıcı verisi klasörünü silmeyin; ardından yeni setup'ı çalıştırın.

## Güncellemeler

Ayarlar → Güncellemeler bölümünden yeni sürümleri denetleyebilirsiniz. Uygulama, indirdiği güncellemenin yayıncı imzasını ve dosya bütünlüğünü doğrular. 0.1.8 ve sonrasında güncellemeler setup ile yüklenir; Windows yönetici izni gerekir. Önceki kurulum konumu hatırlanır.

Bu depo yalnızca Windows kurulum ve sürüm dosyalarını barındırır. Android sürümleri ayrı depoda yayımlanır.

Mercel TV yayın veya abonelik içermez. Kendi Xtream veya M3U kaynağınızı ekleyerek kullanabilirsiniz.
